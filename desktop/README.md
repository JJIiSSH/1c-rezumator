# 1с-резюматор для Mac · 0.2.0

Первая настольная сборка для Mac с Apple Silicon (M1 и новее), macOS 12+. На Intel Mac эта сборка не рассчитана.

## Установка

1. Откройте `dist/1c-rezumator-0.2.0-arm64.dmg`.
2. Перетащите «1с-резюматор» в «Программы».
3. Запустите приложение, выберите ChatGPT или Claude и нажмите «Войти». Завершите официальный вход в браузере. Если страница Claude покажет одноразовый код, вставьте его в появившееся поле.
4. Заполните анкету или загрузите PDF, выберите модель и создайте резюме.

Отдельные Node.js, Python, Codex CLI и API-ключ не нужны. Приложение использует личную подписку и её лимиты. Генерацию в новом аккаунте нужно проверить после входа: авторизация пользователя не входит в установщик.

Тестовая сборка пока без подписи Apple Developer и нотариализации. При запуске загруженного приложения macOS может потребовать разрешение в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Подпись и нотариализация нужны для обычного распространения без этого шага; отключать защиту macOS целиком не нужно.

## Что входит

Существующий интерфейс, анкеты и статусы учеников, выбор подписки, модели и уровня рассуждения, генерация резюме и легенд, метрики, конфигурации 1С, импорт исходного PDF и экспорт PDF. Внутри лежат текущие `rules.md` и `legend.md`; открыть их папку можно через меню приложения «Правила генерации». Промпты поставляются как файлы и не защищены от копирования. Редактирование файлов внутри подписанного приложения в будущем нарушит подпись, поэтому постоянные изменения вносите в исходный проект и выпускайте новую сборку.

Закрытие окна красной кнопкой скрывает его и оставляет генерацию работать. Выход через Cmd+Q проверяет сохранение анкеты; при незавершённой операции предлагает остаться или остановить её. Обновление приложения заменой `.app` не удаляет данные.

## Локальные данные

Обычный запуск хранит данные в `~/Library/Application Support/1с-резюматор/`:

- `data/`: анкеты, результаты, настройки моделей и подключений, резервные копии;
- `codex/`: отдельная авторизация Codex; не пересылайте эту папку другим людям.
- `claude/`: отдельная конфигурация Claude Code; не пересылайте эту папку другим людям.

Меню «Папка с анкетами» открывает `data/`. В установщике нет учеников, исходных PDF, токенов, личной Google-таблицы или пространства Notion. Рабочая браузерная версия на порту 4317 продолжает использовать свою прежнюю базу. Приложение выбирает свободный локальный порт и работает независимо от неё.

## Google Drive и Notion

В верхней панели нажмите «Google Drive и Notion». Эти подключения принадлежат аккаунту ChatGPT, даже если для генерации выбран Claude. Мастер сам предложит переключиться на ChatGPT для их настройки.

1. Нажмите «Установить плагин» для Google Drive или Notion. Ознакомьтесь с доступом и подтвердите установку. Устанавливается только выбранный плагин из официального каталога Codex.
2. Нажмите «Подключить Google Drive» или «Подключить Notion». Откроется официальная страница подключения ChatGPT. Выберите свой аккаунт и предоставьте доступ в браузере.
3. Вернитесь в приложение. Мастер обновит состояние; также доступна кнопка «Проверить подключение».
4. Для Google Drive вставьте ссылку на нужную вкладку таблицы и нажмите «Проверить и сохранить таблицу». Сначала проверяются доступ и заголовки анкеты. Неверная ссылка или структура не заменяют прежнюю настройку.
5. Для Notion нажмите «Найти моё пространство», проверьте название и нажмите «Использовать это пространство». UUID вводить не нужно.

Изменения применяются сразу. Журналы страниц разделены по пространствам; при возвращении в прежнее пространство восстанавливаются его ссылки. Импорт и обновление страниц выполняются отдельно по своим кнопкам. Мастер не импортирует учеников и не создаёт страницы автоматически.

[API установки плагинов Codex](https://developers.openai.com/codex/app-server#api-overview) пока экспериментальный; приложение использует зафиксированную версию runtime. Состояния установки, ограничения администратора, обязательный просмотр разрешений и смена пространства проверены автотестами. Реальное чтение заголовков Google-таблицы и определение пространства Notion проверены на существующих подключениях. Первую выдачу доступа новым аккаунтом пользователь завершает самостоятельно в браузере.

## Следующий этап: веб-версия

После Mac-приложения нужна веб-версия. Интерфейс мастера (`local/public/connections-ui.mjs`) работает через HTTP; проверка подключений, импорт и экспорт находятся в серверных модулях. Их можно использовать повторно. Для публичной веб-версии отдельно нужны пользовательские сессии, изоляция данных и подключений, а также выбранная схема доступа к личной подписке. Текущий localhost-сервер не предназначен для прямой публикации в интернет.

## Сборка из исходников

Сборка выполняется на Mac Apple Silicon с Node.js, Python 3.12 и командными инструментами Apple:

```sh
npm ci
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-build.txt
sh scripts/build-pdf.sh
npm run prepare:service
npm test
npm run build:mac
```

`scripts/prepare-service.mjs` копирует сервис по явному списку разрешённых файлов, создаёт пустой `seed.json`, заменяет личные настройки подключений и добавляет официальные Codex CLI и Claude Code. Тест проверяет отсутствие частных данных и совпадение поставляемых промптов с каноническими. Версии Node-пакетов зафиксированы в `package-lock.json`, PDF-зависимостей в `requirements-build.txt`. Лицензии включены в ресурсы.

Для выпуска с подписью нужно настроить Apple Developer signing/notarization в electron-builder вместо текущего `mac.identity: null`. Текущая сборка не публикуется автоматически и не обновляет себя из сети.
