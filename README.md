# 1с-резюматор

Локальный сервис подготовки резюме программистов 1С и рассказов для собеседований. Интерфейс работает на localhost; генерация использует личную подписку ChatGPT через Codex CLI либо Claude через Claude Code.

Возможности: анкеты учеников с автоматическим сохранением, импорт исходного PDF, выбор конфигураций и редакций 1С, настройка стажа и метрик, генерация и ручное редактирование резюме и легенд, экспорт TXT/PDF, массовая генерация с остановкой, импорт из Google Sheets и создание/обновление страниц Notion без дублей. Готовность отмечается пользователем отдельно от наличия черновика.

## Структура

- `local/`: работающий HTTP-сервер, интерфейс, интеграции и тесты.
- `local/prompts/rules.md` и `legend.md`: канонические промты; читаются при генерации.
- `desktop/`: оболочка Electron для Mac, упаковка официальных клиентов и PDF-модуля.
- `prompt_1c_instruction.md`: ссылка на канонические правила резюме.
- `prompt_1c_task.md`, `candidate_input.example.json`: описание задания и пример входных данных.

## Локальный запуск

Нужны Node.js, Python 3 и официальный Codex CLI и/или Claude Code, авторизованный в нужной подписке. Для работы с PDF:

```sh
python3 -m venv local/.venv
local/.venv/bin/python -m pip install -r local/requirements.txt
REZUMATOR_PYTHON="$PWD/local/.venv/bin/python" npm start
```

Откройте http://127.0.0.1:4317/. Для остановки сервера нажмите Ctrl+C. При необходимости задайте пути к клиентам через `REZUMATOR_CODEX` и `REZUMATOR_CLAUDE`.

Для локальных интеграций можно задать `REZUMATOR_SHEET_ID` и `REZUMATOR_NOTION_WORKSPACE_ID` перед запуском. В Mac-приложении есть мастер подключения Google Drive и Notion. Подробности: [локальная версия](local/README.md), [Mac-приложение](desktop/README.md).

## Проверки

```sh
npm test
```

HTTP-тесты используют временные базы. Рабочие анкеты не изменяются. Сборка и дополнительные тесты Mac-приложения описаны в `desktop/README.md`.

## Личные данные

Новый клон начинает с пустого списка учеников. Анкеты, результаты, настройки, резервные копии и журналы Notion хранятся в `local/.data/`, либо в `REZUMATOR_DATA_DIR`. Они исключены из Git. Входы в аккаунты и ключи не поставляются с исходниками.

Для текущей рабочей базы можно явно указать `REZUMATOR_DATA_DIR` с её абсолютным путём. Исходную базу переносить не требуется. Репозиторий не запускает миграцию или генерацию автоматически.
